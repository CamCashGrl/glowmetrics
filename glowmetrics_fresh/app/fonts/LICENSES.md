# Font licenses

All font files in this folder are licensed under the **SIL Open Font License, Version 1.1**.
The full license texts are included next to the files, as the license requires.
Neither license declares a Reserved Font Name.

These are the exact files Google Fonts served to `next/font/google` (unicode-range subsets
of the variable fonts). They are byte-identical to the ones previously downloaded at
build time; only the file names were changed to describe each unicode range.
